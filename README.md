#Language Translation Tool

A simple and user-friendly Language Translation Tool that allows users to enter text, select a source language and target language, and translate the entered text using a translation API.

📌 Project Overview

The Language Translation Tool provides an easy way to translate text between different languages through an interactive web interface. Users can enter their text, choose the required languages, and receive the translated output clearly on the screen.

This project was developed as Task 1: Language Translation Tool to practice frontend development, API integration, and user interaction.

✨ Features
📝 Enter text for translation
🌐 Select source language
🎯 Select target language
🔄 Translate text using a translation API
📋 Copy translated text
📱 Responsive and user-friendly interface
⚡ Clear and easy-to-read translation output

🛠️ Technologies Used
HTML5 – Structure of the web application
CSS3 – Styling and responsive design
JavaScript – Application logic and API integration
Translation API – Processing translation requests
Git & GitHub – Version control and project hosting
